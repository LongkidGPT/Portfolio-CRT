# Kid Long — Portfolio 2.0

Interactive Next.js portfolio with a 64-frame CRT portrait, responsive project selector, shareable case routes, and intercepted full-screen overlays.

## Commands

```bash
npm run dev
npm test
npm run lint
npm run build
npm run test:e2e
```

## Routes

- `/about`
- `/work/business`
- `/work/brand-system`
- `/work/product-launch`
- `/work/launch-event`

Replace project metadata and media requirements in `lib/portfolio/projects.ts`. Replace placeholder case copy and chapter structure in `components/portfolio/CaseTemplate.tsx` and `components/portfolio/AboutTemplate.tsx`.
